# Benchmarks and budgets

Owned by WP-36 (created by WP-00). This directory holds the hyperfine scenario definitions and the committed baseline
history of the end-to-end performance gates (ARCHITECTURE §12, research 10 §7.11).

| What | Where | Run by |
|---|---|---|
| end-to-end scenarios B1…B12 (deterministic repos generated by `cargo xtask bench setup`) | `bench/` | `cargo xtask bench run` |
| baselines (pre-commit 4.6.2 oracle `pc462-py312`, pinned prek) and the JSON history | `bench/` | `cargo xtask bench gate` |
| criterion micro-benches (pyre kinds, shuffle + partition, tagging tiers, YAML manifest load, argparse hook-impl argv, `len_cjk`) | `crates/snp/benches/` | `cargo bench -p snp` |
| allocation budget (B3 ≤ 2 MB total allocated) | `crates/snp` feature `dhat-heap` | `cargo xtask bench` |
| release-mode `#[ignore = "perf"]` threshold tests (3× safety factor) | the owning crates | CI job `perf-smoke` |

The gate fails on a median regression above 5 % with non-overlapping 95 % confidence intervals, or on any breach of
a hard budget (ARCHITECTURE §12.1, §12.3). Timing gates use the `dist` profile; spawn budgets use a
`--features testing` build with `SNP_TEST_SPAWN_LOG`.
