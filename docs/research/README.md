# snp research base (spec references `NN §x`)

These files are the research specifications the design in `docs/ARCHITECTURE.md` cites as `NN §x`
(`02 §7.2` = `02-run-pipeline.md` section 7.2). `01 Addendum` = the normative regex addendum at the end of
`01-config-schema.md` (§A.0–§A.11); it overrides every earlier regex statement in any document.

## Provenance and known gaps

The original working copies lived in a session scratch directory that was wiped by a machine reboot on
2026-10-08. They were reconstructed from the authoring sessions' transcripts (every `Read` of each file after its
final edit, plus a replay of the `Write`/`Edit`/heredoc operations that produced it). Line numbers cited in the design
(`03 l.992`) refer to the original files and may be off by a few lines in the files below; section numbers are exact.

`pycompat-proto/` is the verified Python-semantics prototype (vendored by WP-00). Its committed vector files were
generated by `scripts/gen_pycompat_vectors.py` under CPython 3.12.3 and 3.13; the JSON outputs were lost and are
regenerated by WP-11 (the generator script itself may need the last two recorded fixes re-applied; see WP-11).

rebuilds the vector sets from the Addendum's §A.8 test plan.
